分数和推算是怎么来的

排盘：按太阳黄经计算节气，以立春换年、节令换月；日柱按儒略日推算；夜子时可选换日或不换日。大运按年干阴阳与性别定顺逆，以出生到节令的天数折算起运岁数（三天为一年）。

喜用神：先看出生月份，冬月以火调候、夏月以水调候；再按日主强弱扶抑（身弱取印比，身强取财官食伤）。这是简化的自动规则，复杂命局建议再请人细看。

分数：每个干支按五行喜忌与十神对各方面的作用打分，并计入与原局的冲合刑害和天乙贵人。每日 = 日柱 + 0.35×流月 + 0.2×流年 + 0.15×大运；每月 = 流月 + 0.4×流年 + 0.2×大运；每年 = 流年 + 0.5×大运。换算成 0–100 分：76–100 大吉，56–75 吉，51–55 小吉，21–50 小凶，6–20 凶，0–5 大凶。

易经：日、周用汉代卦气值日，月用十二消息卦，年用干支起卦；与本命卦（八宅命卦）按梅花易数体用论生克。九宫飞星按每年入中宫之星沿洛书顺序排布。命理仅供参考，不能代替你自己的判断。
